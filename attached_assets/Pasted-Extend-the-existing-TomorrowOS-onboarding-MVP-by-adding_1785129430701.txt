==================================================
1. CRITICAL PRODUCT POSITIONING
==================================================

Replit and Vercel are both Guided Setup options, but they are not identical.

Replit path:

- Build using Replit Agent
- Configure Replit Secrets
- Preview inside Replit
- Publish through Replit

Vercel path:

- Build using v0
- Connect Vercel Marketplace services or external services
- Configure Vercel Environment Variables
- Preview through a Vercel deployment
- Publish to Vercel

Use this terminology consistently:

Vercel
Build with v0 and deploy to Vercel.

Do not call the AI builder simply “Vercel”.

v0 is the AI-assisted building interface.
Vercel is the hosting and deployment platform.

23. TROUBLESHOOTING
==================================================

Extend the Need help? drawer with Vercel-specific content.

------------------------------------------
V0 DOES NOT FOLLOW THE SETUP GUIDE
------------------------------------------

- Confirm the exact TomorrowOS setup prompt was used.
- Confirm `VERCEL_SETUP.md` exists in the installed SDK version.
- Start a new focused v0 chat when prior instructions conflict.
- Do not paste secrets into the chat.

------------------------------------------
THE BUILD STOPS OR RUNS OUT OF CREDITS
------------------------------------------

- Save the current project.
- Review the current v0 plan and usage.
- Continue when additional usage is available.
- Avoid repeatedly regenerating the entire application for a small change.

------------------------------------------
DATABASE DOES NOT CONNECT
------------------------------------------

- Confirm the Marketplace integration is connected to the correct Vercel project.
- Confirm the required variable exists.
- Confirm it is enabled for Preview and Production.
- Confirm the TomorrowOS variable mapping is correct.
- Redeploy after changing variables.

Links:

- Open Supabase guide
- Open Neon guide
- Open Vercel Environment Variables

------------------------------------------
MEDIA STORAGE DOES NOT CONNECT
------------------------------------------

For Cloudinary:

- Confirm all three credentials exist.
- Confirm they are enabled in the correct environments.
- Confirm the values come from the same Cloudinary environment.

For Vercel Blob:

- Confirm a Blob store is connected.
- Confirm the approved authentication method is configured.
- Confirm the upload route matches the TomorrowOS implementation.
- Redeploy after changing configuration.

------------------------------------------
PREVIEW WORKS BUT PRODUCTION FAILS
------------------------------------------

- Confirm Production Environment Variables are present.
- Confirm the production database is reachable.
- Confirm storage variables are available in Production.
- Confirm a redeployment occurred after configuration changes.
- Review Vercel Runtime Logs.

------------------------------------------
DEVICE CANNOT STAY CONNECTED
------------------------------------------

- Confirm the current TomorrowOS Vercel support status.
- Review function and connection limits.
- Confirm Fluid compute or the approved realtime architecture is configured.
- Review Runtime logs.
- Move the backend connection service to an approved persistent host when required.

Do not present unverified WebSocket fixes as guaranteed solutions.
