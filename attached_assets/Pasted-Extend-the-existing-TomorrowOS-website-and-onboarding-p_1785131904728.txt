ANALYTICS

Optional

------------------------------------------
MARKETING
------------------------------------------

Default:

Off

Description:

Used for advertising or campaign measurement when configured.

Toggle:

Optional

------------------------------------------
ACTIONS
------------------------------------------

- Save preferences
- Accept optional cookies
- Reject optional cookies
- Reset preferences

Store only the consent preference locally.

Do not enable analytics or marketing scripts merely because the page exists.

Create a central consent service:

cookieConsent = {
  necessary: true,
  analytics: boolean,
  marketing: boolean,
  updatedAt: timestamp,
  version: string
}

All optional scripts added in the future must read this consent state before loading.

Do not load an analytics or marketing script before permission is granted.

When no optional scripts are currently configured, show:

No optional analytics or marketing tools are currently active. Your saved preference will be available when optional services are added.

Do not claim the settings block technologies that have not actually been integrated with the consent system.
