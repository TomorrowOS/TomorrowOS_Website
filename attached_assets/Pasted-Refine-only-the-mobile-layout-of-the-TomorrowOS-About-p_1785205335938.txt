Refine only the mobile layout of the TomorrowOS About page.

Do not redesign the desktop About page.
Do not change any wording, section order, links, icons or destinations.
Do not remove content.
Do not convert the main About content into accordions.

The current mobile page is excessively long because repeated feature and principle items retain desktop-style vertical spacing.

The objective is to make the page materially shorter and easier to scan while preserving the approved Figma design language.

==================================================
1. PRESERVE DESKTOP
==================================================

Do not alter the About page at desktop or tablet widths unless required to prevent a regression.

The existing desktop composition must remain unchanged at:

- 1024px
- 1440px

Apply the following refinements only below the mobile breakpoint.

==================================================
2. REMOVE DESKTOP HEIGHT RULES ON MOBILE
==================================================

Audit the About-page sections for:

- fixed heights
- min-heights
- large grid row heights
- desktop padding values
- large margins between icon, heading and copy
- vertically centred desktop cards

On mobile:

- set repeated feature items to `height: auto`
- remove unnecessary `min-height`
- do not vertically centre content inside tall containers
- allow every item to size naturally to its content

Do not remove spacing globally. Limit the change to the About-page mobile components.

==================================================
3. CONVERT FEATURE ITEMS TO COMPACT MOBILE ROWS
==================================================

For repeated items in sections such as:

- Build and keep ownership of everything
- Built and maintained by people from digital signage
- Apache 2.0 in plain terms
- Free to build on, sustainable for the long term

Use a compact mobile row pattern.

Structure:

[icon] [title and description]

Recommended mobile layout:

- display: grid
- grid-template-columns: 24px minmax(0, 1fr)
- column gap: 14–16px
- align-items: start
- padding: 24px 0
- no fixed height

Icon:

- width: 22–24px
- height: 22–24px
- aligned with the title
- no large empty space underneath

Text:

- title directly beside the icon
- description 6–8px below the title
- preserve existing fonts and weights

Add a subtle divider between consecutive items:

- 1px neutral-grey
- no divider after the final item

Do not place each item inside a heavy card.

Do not compress the page so tightly that sections lose separation.

Do not reduce body text merely to shorten the page.
