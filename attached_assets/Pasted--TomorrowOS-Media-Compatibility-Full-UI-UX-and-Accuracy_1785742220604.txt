# Critical distinction

This page must distinguish between:

## Hardware capability

A device manufacturer states that the hardware can decode or display a media format.

## Runtime support

The TomorrowOS runtime is designed to process or play the media type.

## Physically tested

The exact file was tested on a recorded device, firmware and TomorrowOS runtime combination.

## Validated media profile

The media profile passed the defined TomorrowOS validation workflow.

## Production recommended

The profile is recommended for real deployments within the stated platform limitations.

## Requires validation

The format may work, but the exact combination has not completed testing.

## Unsupported

The format or profile is known not to work correctly in the relevant combination.

Do not treat hardware datasheets as TomorrowOS test evidence.

Do not use “supported” and “validated” interchangeably.
