Production feature flag

Implement the safest production feature flag supported by the existing architecture.

Recommended name:

VITE_ENABLE_LEARN

Behaviour:

When true
Existing /learn routes behave exactly as they currently do.
Useful for local development, previews and future relaunch.
When false or absent
/learn
/learn/*

must resolve to the existing NotFound experience.

They must not render Learn content.

They must not be prerendered as public production pages.

They must not appear in the sitemap.

They must not appear in smoke coverage as publicly available production routes.

They must not appear in mirror-host route declarations as active routes where this would expose them.

The feature flag must be handled consistently across:

application routes;
SEO configuration;
prerendering;
smoke tests;
route-sync validation;
mirror-host configuration;
production builds;
development builds.

Do not weaken the existing route-sync safeguard.

Update it so feature-gated routes are explicitly understood rather than silently excluded.

The validation should fail if:

a disabled Learn route is accidentally indexable;
a disabled Learn route appears in the production sitemap;
a public navigation link points to a disabled route;
a disabled Learn page is prerendered in the production build;
feature-gated route configuration drifts between relevant files.

Default production state:
