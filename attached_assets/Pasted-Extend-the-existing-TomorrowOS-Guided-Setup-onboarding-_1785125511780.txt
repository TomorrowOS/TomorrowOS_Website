==================================================
1. CRITICAL PRODUCT RULE
==================================================

TomorrowOS.org is providing an instructional guide.

The content upload, playlist creation, scheduling and publishing actions happen inside the user’s published CMS.

The onboarding website is not currently integrated with:

- The CMS media library
- Cloudinary uploads
- CMS playlists
- CMS schedules
- CMS devices
- Physical screen playback
- Runtime telemetry

Therefore, the guide must not imply it can:

- Upload a file
- Create a playlist
- Save a playlist
- Publish content
- Confirm content is playing
- Remove content from a device
- Read the current screen state

The guide may:

- Explain the process
- Show screenshots
- Link to the CMS
- Link to Cloudinary and compatibility guides
- Copy example values
- Save non-sensitive onboarding progress locally
- Let the user confirm they completed an external action
- Show troubleshooting information

Use user-confirmed language:

- I uploaded my media
- I created and saved my playlist
- I published my playlist
- My playlist is playing correctly
- You confirmed this step

Do not use verified language unless a real integration exists:

- Upload successful
- Playlist created
- Content deployed
- Screen verified
- Playback confirmed by TomorrowOS

MY ASSET WILL NOT UPLOAD
------------------------------------------

- Cloudinary is configured
- File is within the current plan limit
- Media format is supported
- Internet connection is stable

Actions:

- Open Cloudinary guide

------------------------------------------
MY PLAYLIST WILL NOT SAVE
------------------------------------------

Check:

- Playlist name has been entered
- At least one asset has been added
- Image durations are valid
- Schedule fields are complete
- No upload is still in progress

Action:

Open my CMS

------------------------------------------
THE PLAYLIST DOES NOT APPEAR IN PUBLISH
------------------------------------------

Check:

- Playlist was saved
- Correct CMS environment is open
- Playlist list has refreshed
- Playlist has not been archived or removed

------------------------------------------
THE SCREEN IS OFFLINE
------------------------------------------

Check:

- Display has power
- TomorrowOS Runtime is running
- Network is connected
- Screen remains paired to this CMS

Actions:

- Open device troubleshooting
- View platform guides

------------------------------------------
THE PLAYLIST WAS PUBLISHED BUT DOES NOT PLAY
------------------------------------------

Check:

- Physical screen is online
- Playlist is assigned to the correct screen
- Schedule is currently active
- Changes were saved
- Media format is supported
- Screen has had time to download the content

------------------------------------------
THE SCREEN IS BLACK
------------------------------------------

Check:

- Playlist contains valid media
- Assets uploaded successfully
- Media format is compatible
- Schedule is active
- Display orientation is correct
- Target screen supports the media encoding

Actions:

- Check media compatibility
- Open device troubleshooting
- Open Cloudinary guide

Do not display raw technical errors by default.

Provide a collapsed:

View technical details

option when appropriate.
