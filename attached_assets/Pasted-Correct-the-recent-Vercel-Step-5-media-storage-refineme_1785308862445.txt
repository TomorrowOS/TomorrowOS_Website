4. LARGE MEDIA UPLOADS
==================================================

Digital-signage videos will commonly exceed small serverless request limits.

Do not implement all uploads through a server-upload route limited to small files.

Use the approved Vercel Blob client-upload architecture for large media where required.

The implementation should:

- Request an authorised upload token from the backend
- Upload the file directly using the approved Blob client flow
- Return the completed Blob URL to the CMS
- Store the resulting URL in the application database
- Never expose unrestricted Blob credentials to the browser
- Show upload progress where the existing CMS design supports it
- Handle failed or interrupted uploads clearly

Small server uploads may remain supported where appropriate, but they must not be the only path for video uploads.

Do not invent a custom upload mechanism when the supported Vercel Blob pattern is available.
