Refine and complete the TomorrowOS onboarding entry flow and Terminal journey.

The application already contains:

- Guided Setup
- A partial Terminal flow
- A Server SDK integration example
- An API Integration option
- Shared player installation, pairing and content guides

Do not rebuild the Guided Setup journey.

The objective of this task is to:

1. Create one consistent onboarding entry flow.
2. Clearly separate creating a new product from connecting an existing product.
3. Build the complete Start a new project → Terminal journey.
4. Remove Supabase, Cloudinary and Replit assumptions from the primary Terminal path.
5. Preserve Server SDK and API Integration as the two paths for an existing application.
6. Merge all successful paths into the shared player, pairing and content journey.

Preserve the existing TomorrowOS visual language:

- Roboto
- White background
- Black primary actions
- Light-grey cards and borders
- Minimal colour
- No gradients
- No decorative marketing illustrations
- Clear hierarchy
- Calm, premium developer-product feel
- Responsive desktop and mobile layouts
