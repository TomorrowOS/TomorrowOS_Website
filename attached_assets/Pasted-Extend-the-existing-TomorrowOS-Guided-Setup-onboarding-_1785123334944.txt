==================================================
1. CRITICAL PRODUCT RULE
==================================================

The TomorrowOS onboarding website is a guide.

It is not currently integrated with:

- The user’s generated CMS
- Replit
- Samsung displays
- The TomorrowOS Runtime running on a display
- Device pairing
- Device online status

Therefore, do not create controls that imply TomorrowOS.org can:

- Download a player into the user’s CMS
- Install the Samsung Runtime remotely
- Read the pairing code
- Enter a pairing code
- Connect the display
- Reboot the display
- Verify the display is online
- Deploy content

The guide may:

- Show instructions
- Show screenshots
- Copy the Samsung installation URL
- Open the user’s CMS when a locally saved CMS URL exists
- Link to the Samsung setup guide
- Link to compatibility information
- Let the user mark instructional steps complete
- Display troubleshooting
- Save non-sensitive guide progress locally

Use user-confirmed language:

- I completed this step
- I can see the pairing code
- I confirmed the screen is online
- Marked complete

Do not use automatic or verified language unless a real integration exists:

- Device connected
- Player installed
- Runtime verified
- Screen online
- Pairing successful
- Health check passed
